# Agent answer regression, 2026-10-30

The failed run's two lexical queries were an AND of all tokens within each chunk. Against the original generation-7 index, both returned zero; the index refresh left the generation unchanged. Direct read-only SQL showed that the shorter `Mabel roadmap` query matched 45 chunks and a BM25-ranked OR search for the original queries placed the relevant roadmap in the top results. Hybrid retrieval was degraded to lexical because embedding was unavailable. The fix falls back to ranked any-term matching only when no all-term result exists, retains identical structured filters, and labels the matching strategy.

A preexisting read-only loop guard counted six distinct fact-gathering rounds as a stall even for a read-only research objective. It now applies that particular guard to coding or declared-artifact work; the existing repeated-call and round budgets remain. Forced synthesis receives bounded source-attributed excerpts from already authorized reads, and an empty or failed synthesis can return explicitly incomplete excerpts rather than the unrelated canned apology. No new reads or grants are implied. The previously uninstrumented non-streaming grace synthesis now emits its duration. Its invocation plausibly accounts for the observed 30-second gap, but the old trace did not record it, so the exact cause is not established.

An Arch live run exposed another recovery bug: after provider-confirmed input overflow, the ordinary runtime trimmed the prompt but retried with `max_tokens=1`, computed against the old oversized input. The retry now reserves up to 1024 tokens after such a trim, bounded by the originally requested allowance. Other context and authorization checks remain unchanged. Source-ID presentation is scoped to vault results and removes invalid native-index `#note-` links rather than presenting them as application-note identifiers.

The original prompt was repeated using the same Strata model and authorized read-only vault tools in an isolated production agent-loop invocation. The final run used authenticated provider context metadata, which advertised a 32,768-token window. It returned a substantive document and roadmap summary in 110.36 seconds, using eight model requests, 167,504 cumulative provider input tokens and 3,559 output tokens. This is not a controlled apples-to-apples timing comparison with the older Windows/UI run, which included a different machine, configuration and conversation context. An earlier Arch test without the route's context resolution failed after a one-token retry (131.26 seconds); a later direct test produced a useful summary but contained an invalid note link, prompting the identity safeguard.

The migrated machine had a valid local grant for Core of Truth but no explicit knowledge-vault target. `data/vault_target.json` was created only if absent, pointing to that already granted directory. No Markdown was modified.
