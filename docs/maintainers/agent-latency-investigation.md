# Agent latency investigation

The supplied trace shows 21 model requests, 484.9 s model request wall time, 13.25 s observed tool wall time, 332,030 cumulative provider-reported input tokens, and 26,723 input tokens in the final request. The model made one call per iteration in this trace, although later iterations invoked the existing concurrent retrieval batch. The redacted arguments do not establish which reads overlap or whether more reading was warranted. No research dispatch appears; the trace lacks the advertised tool names, so it cannot establish whether delegation was offered or why it was not selected. A bounded local summary does not inherently require delegation.

The timing fields `prompt_ms` and `predicted_ms` are provider-reported fields, not necessarily exhaustive wall-clock phases. The difference between these and request wall/first-token durations is an unattributed difference, not proof of queueing, network latency, cache behavior or GPU scheduling. A stable session identifier and `cache_prompt` hint are sent to endpoints classified as self-hosted OpenAI-compatible; whether Strata honors them and cache-hit data is unavailable from this trace. Establish that from Strata's own metrics before changing inference settings.

The tool event display has a 10,000-character preview cap. The model receives the separately formatted full tool result; preview truncation is not proof that its input was truncated. New events report preview and full result sizes independently. The generic `unverified` completion state can mean no declared artifact or executable verifier; it is not a source-grounding verdict. The trace did not retain the original completion reason, so this is an architecture-based explanation, not proof of the specific run's reason.

The index read API produced both raw text and a second numbered copy; knowledge tool responses now omit only the duplicate numbered rendering and retain raw source, line boundaries, hash and staleness. The underlying index API is unchanged. Future trace events expose exact same-tool/same-argument repetitions within a turn using in-memory fingerprints, unattributed timing differences when inputs are usable, full result bytes, research and batch schema advertisement in the ordinary runtime, and research worker model metadata when returned. Fingerprints and raw arguments are not persisted. Completion basis is exposed for the known generic-verifier case. Cross-model metadata occurs after the worker returns, not as a live per-child stream.

These changes do not deduplicate operations or enforce early completion: safe reuse must validate fresh content, resource grants and relevant dependencies. They do not establish a wall-clock reduction or the reason for Strata's delays. Live comparisons, provider queue/cache telemetry, compact-runtime schema-offering diagnostics, evidence-aware round-trip reduction and independently validated citations remain future work. No model, vault, authorization or provider settings are changed.
